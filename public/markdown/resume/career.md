## 1. 근태관리 + 출입 보안 시스템 웹 리뉴얼

### 📅 기간

2024.01 ~ 2024.03

### 📌 프로젝트 개요

레거시 클래스 컴포넌트 기반 구조로 인해 유지보수 비용이 증가하고,
대량 데이터 렌더링 및 사용자 인터랙션 시 성능 저하 문제가 발생하던 시스템을
전면 리뉴얼하여 구조 개선 및 UX/성능을 동시에 개선한 프로젝트입니다.

### ⚠️ 주요 문제

- 클래스 컴포넌트 중심의 레거시 구조 → 확장성과 유지보수성 저하
- 사용자 인터랙션 시 잦은 UI 렉 발생
- 100건 이상의 데이터 테이블 렌더링 시 메모리 사용량 증가 및 성능 저하
- 중복 로직 및 분산된 코드 구조 → 개발 생산성 저하
- UI 디자인 시스템 부재 → 일관성 없는 UX

### 💡 해결

#### 아키텍처 개선

- 클래스형 컴포넌트를 함수형 컴포넌트 구조로 전환
- 로딩 / 요청 / 에러 로직을 Custom Hook으로 공통화
- 공통 리소스와 라우트 리소스를 분리하여 프로젝트 구조 재설계

#### 성능 최적화

- 메모이제이션 및 컴포넌트 책임 분리를 통해 불필요한 리렌더링 제거
- dynamic import 기반 코드 스플리팅 적용
- 이미지 최적화 및 렌더링 구조 개선

#### UI/UX 개선

- 디자인 시스템 정의 및 컴포넌트 공통화
- 로딩/에러 상태 UI 명확화
- 사용자 인터랙션 피드백 개선

### ✨ 성과

- Lighthouse 성능 점수 65 → 92 개선
- 사용자 인터랙션 시 발생하던 UI 렉 제거
- 대량 데이터 처리 시 렌더링 안정성 확보
- 코드 구조 개선으로 유지보수성 및 개발 생산성 향상

## 3. 근태 관리 웹 애플리케이션

### 📅 기간

2025.07 ~ 2025.12

### 📌 프로젝트 개요

300명 이상이 사용하는 근태 관리 시스템으로, 관리자 웹과 직원 웹을 함께 개발했습니다.
관리자 화면에서는 수천 건 이상의 근태 데이터를 조회·선택·관리해야 했기 때문에, 대량 데이터 테이블의 렌더링 성능과 검색 UX를 함께 만족시키는 구조 설계가 주요 과제였습니다.

### ⚠️ 주요 문제

- 수천 건 이상의 근태 데이터를 한 번에 렌더링하면서 성능 저하 발생
  - 스크롤 시 프레임 드랍 발생
  - 행 선택 및 인터랙션 시 UI 지연 발생
  - 대량 DOM 렌더링으로 인한 초기 렌더링 비용 증가
- 기존 테이블 구조의 비효율
  - selected 상태를 글로벌 상태로 관리
  - 각 행 하위에 선택 여부를 판단하는 Container 컴포넌트를 배치
  - row 수만큼 불필요한 컴포넌트 계층이 증가해 대량 데이터 렌더링 비용이 커지는 문제 발생

### 💡 해결

- 대량 데이터 렌더링 성능 개선을 위해 테이블에 Virtualization 도입
  - 화면에 보이는 영역 중심으로 row를 렌더링하도록 변경
  - 불필요한 DOM 생성을 줄여 초기 렌더링 비용과 스크롤 성능 문제 개선
  - 대량 데이터 조회 상황에서도 안정적인 스크롤 경험을 제공하도록 구조 개선

- row 렌더링 구조 최적화
  - 기존 Container 컴포넌트를 제거하고 row 컴포넌트 중심 구조로 단순화
  - row 컴포넌트에 메모이제이션을 적용
  - 각 row에는 선택 여부만 나타내는 isSelected boolean props를 전달하도록 변경
  - selected 상태를 Set 기반으로 관리하여 각 row의 선택 여부를 O(1)에 확인하도록 개선

- 인터랙션 처리 경량화
  - hover 및 인터랙션 스타일을 React state가 아닌 Tailwind CSS의 group 기능으로 처리
  - 불필요한 상태 변경과 리렌더링을 줄여 UI 반응성 개선

### ✨ 성과

- Virtualization을 통해 대량 데이터 테이블의 초기 렌더링 비용과 스크롤 성능 문제 개선
- row 구조 단순화와 메모이제이션으로 선택 및 인터랙션 시 UI 지연 완화
- 성능 최적화와 사용자 탐색 경험을 함께 고려한 대량 데이터 테이블 구조로 개선

# 📌 Other Projects

## 현대중공업 식수 관리 시스템

### 📅 기간

2023.02 ~ 2023.08

### 📌 프로젝트 개요

사업장 식당 단말기에서 발생하는 데이터를 기반으로 실시간 식수 현황을 모니터링하는 관리자 시스템을 구축했습니다.

다수 사업장에서 발생하는 식수 이벤트를 실시간으로 수신하고, 운영자가 사업장별 식당 상태와 이용 현황을 즉시 파악할 수 있도록 관리자 대시보드를 개발했습니다.

특히 빈번하게 발생하는 실시간 데이터 업데이트 상황에서 UI 반응성과 렌더링 성능을 안정적으로 유지하는 것이 주요 과제였습니다.

### ⚠️ 주요 문제

- 다수 사업장의 식당 단말기에서 실시간 식수 이벤트가 지속적으로 발생
- MQTT 기반 실시간 데이터 수신 시마다 React state를 즉시 갱신할 경우 잦은 리렌더링으로 UI 성능 저하 우려
- 실시간 데이터 반영은 필요하지만, 전체 화면이 매번 리렌더링되면 사용자 경험 저하 가능성 존재

### 💡 해결

- ref를 활용한 실시간 데이터 배치 처리
  - 이벤트가 들어올 때마다 즉시 state를 업데이트하지 않고, ref에 최신 데이터를 임시 저장
  - 일정 주기에만 React state로 반영하여 렌더링 빈도 제어
  - 짧은 시간에 여러 이벤트가 들어와도 state 업데이트 횟수를 줄여 불필요한 리렌더링 방지
- 메모이제이션을 통한 렌더링 최적화
  - 변경되지 않은 리스트 항목은 재렌더링되지 않도록 컴포넌트 구조 개선
- 안정적인 key 설계를 통한 리스트 렌더링 최적화
  - 고유 식별자를 기준으로 key를 부여
  - 실시간 데이터 업데이트 시 React가 기존 DOM과 컴포넌트 인스턴스를 안정적으로 재사용할 수 있도록 처리

### ✨ 성과

- 수천~수만 명 규모의 식수 데이터를 실시간으로 원활히 모니터링할 수 있도록 성능 구축
- 운영자가 식당 상태를 직관적으로 확인할 수 있는 관리자 대시보드 구축
